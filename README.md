# آرتین‌تک (ArtinTech)

سایت خدمات دیجیتال و خودسازی — طراحی وب، پایتون، TTS فارسی، تدوین، ترجمه، اتوماسیون، سئو و تصویرسازی هوش مصنوعی.

## ویژگی‌ها
- طراحی مدرن، ریسپانسیو و RTL
- صفحه خدمات با ۹ دسته تخصصی
- بلاگ خودکار با مقالات سئو‑دوست
- سئو کامل (متا، Open Graph، canonical)
- بدون وابستگی به CDN خارجی (مناسب ایران)
- فرم تماس با fallback ایمیل

## اجرا
فایل `index.html` را مستقیماً در مرورگر باز کن یا روی GitHub Pages میزبانی کن.

## ساختار
- `index.html` — صفحه اصلی
- `styles.css` — استایل
- `main.js` — منوی موبایل، reveal، بلاگ، فرم
- `posts/` — مقالات بلاگ
